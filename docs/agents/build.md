# Build and run

This repo uses pnpm (packageManager pinned in package.json).

## Common commands

- Install deps: `pnpm install`
- Dev server: `pnpm dev`
- Build: `pnpm build`
- Typecheck: `pnpm typecheck` (runs Next.js typegen and `tsc --noEmit`)
- Lint: `pnpm lint:fix` (Biome + autofix)
- Format: `pnpm format` (Biome)
- Tests: `pnpm test` (runs `bun test`)

## Local dev & parallel worktrees

`pnpm dev` self-provisions an isolated stack for the current git worktree:

1. A shared Postgres must be running: `docker compose up -d --wait db`.
2. The `predev` hook derives a database name from the current branch (`main_<branch>`),
   creates it in the shared Postgres if missing, runs `db:migrate` + `db:seed` on first
   creation, and writes `DATABASE_URL` + `BETTER_AUTH_URL` into `.env.local`.
3. The dev server runs through [portless](https://github.com/vercel-labs/portless),
   which assigns a free port and serves the app at `https://<branch-derived-name>.localhost`.

Use the URL printed by `pnpm dev`. In the normal portless path, the app is not
served at `localhost:3000`.

This lets multiple worktrees (e.g. one per agent/issue) run concurrently with no port
or data collisions. Override the Postgres base with `POSTGRES_BASE_URL`.

### How a fresh worktree gets provisioned

Worktrees Claude Code creates (`--worktree`, subagent worktrees, desktop parallel
sessions) are ready with zero manual steps:

- **Secrets are copied in.** `.worktreeinclude` lists the gitignored files Claude Code
  copies into each new worktree (`.env`). It deliberately does
  **not** include `.env.local` — that file is per-branch and regenerated by `predev`.
- **Deps are installed.** A `SessionStart` hook (`.claude/hooks/worktree-setup.sh`) runs
  `pnpm install` when `node_modules` is missing — a no-op in the main checkout and any
  already-installed worktree, and near-instant otherwise thanks to
  `enableGlobalVirtualStore` (symlinks into the shared global store).
- **Env precedence:** `next dev` loads `.env` (shared secrets, copied in) and then
  `.env.local` (branch-specific `DATABASE_URL` + `BETTER_AUTH_URL`, written by `predev`);
  `.env.local` wins. So a worktree is fully provisioned the first time you run `pnpm dev`.

Worktrees created manually with `git worktree add` (outside Claude Code) skip the
`.worktreeinclude` copy, but `provision-db.ts`'s `bootstrapEnvFile()` fallback seeds
`.env` from the primary worktree on first `pnpm dev`, so they self-heal too.

### One-time machine setup: portless proxy

The portless proxy binds port 443 and **must be started once per machine** before
`pnpm dev` — it cannot self-start headless (it needs sudo and a TTY):

```
sudo portless proxy start --https
```

Without portless installed, `pnpm dev` falls back to a plain `next dev` on a
deterministic per-branch port (`http://localhost:<deterministic-branch-port>`).

## Other useful scripts

- Database: `pnpm db:generate`, `pnpm db:migrate`, `pnpm db:push`, `pnpm db:studio`, `pnpm db:seed` (see `docs/agents/database.md` before using these)
- Auth schema generation: `pnpm auth:generate`
- Email dev server: `pnpm email:dev` (port 3001)
- Clean build artifacts: `pnpm clean`
